# Accepted Specifications

Accepted specs are the authoritative specification set.

Rules:

- every accepted spec lives in this folder;
- every accepted spec has status `Accepted`;
- every accepted spec is declared in `manifest.json`;
- accepted specs must not contain unresolved `agent-review` blocks;
- accepted specs must contain a `review_resolution` block;
- accepted spec relationships are authoritative in `manifest.json`.
